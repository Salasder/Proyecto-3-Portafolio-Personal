En esta sección encontrarás información básica sobre las principales tecnologías utilizadas en el desarrollo web.

¿Qué es HTML y para qué sirve?

HTML es un lenguaje de marcado utilizado para crear y estructurar el contenido de las páginas web.

Con HTML podemos crear títulos, párrafos, imágenes, enlaces, listas, formularios y diferentes secciones dentro de una página web.

Leer más sobre HTML →

¿Qué es CSS?

CSS es un lenguaje utilizado para dar estilo y diseño a las páginas web.

Permite modificar colores, tamaños, tipografías, espacios y la distribución de los elementos. También permite adaptar el sitio a diferentes pantallas.

Leer más sobre CSS →

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite añadir interactividad a las páginas web, responder a eventos y modificar elementos del contenido.

Aunque este portafolio está construido sin JavaScript, este lenguaje es útil para desarrollar funcionalidades más avanzadas.
